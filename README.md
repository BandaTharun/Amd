# Finding Similar Items

Implementation of a similar-item detection system for textual
documents from the New York Times Articles & Comments (2020) dataset.

## Project

Algorithms for Massive Datasets
Master in Computer Science
University of Milan
Academic Year 2025/26

## Approach

The project implements:

1. Text preprocessing
2. Shingling
3. Jaccard similarity
4. MinHash
5. Locality-Sensitive Hashing (LSH)
6. Candidate pair generation
7. Exact similarity verification
8. Evaluation and scalability experiments

## Dataset

New York Times Articles & Comments (2020), downloaded dynamically
from Kaggle during notebook execution.

The dataset is not included in this repository.
